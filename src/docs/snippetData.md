# 基本的な書き方

```c
printf("hello, %d", 100);
```

## フォーマット指定子

- %c : char
- %d int, short
- %u unsigned int, unsigned short

# ネットワークの基礎

## 1. インターネットとは

世界中のコンピュータが相互接続された巨大ネットワーク。

## 2. IP とポート番号

- IP：住所
- ポート：部屋番号
  例：`192.168.1.2:3000`

## 3. HTTP の流れ

1. クライアントがリクエスト
2. サーバーがレスポンス
3. JSON や HTML を返す

## 4. Web の基本構造

- フロントエンド（UI）
- バックエンド（API）
- データベース（永続化）

## 5. DNS の役割

名前 → IP アドレスへ変換
例：`google.com` → `142.250.xxx.xxx`
